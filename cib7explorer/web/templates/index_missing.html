CIB7_DB_PASSWORD=…
CIB7_CLASSIFICATION=test     # unset means unknown, and then values stay hidden
CIB7_PROFILE_NAME=my-environment

The profiles file deliberately lives outside the repository and holds only references to secrets, never a password itself. The environment profile likewise keeps only the reference to CIB7_DB_PASSWORD, not the value.
