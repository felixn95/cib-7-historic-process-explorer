Runtimes are distributions (median and p90), deliberately not averages — for process runtimes an average hides the distribution it came from. “Incidents (open)” are open incidents of running instances from act_ru_incident; the incident history is only written at history level FULL, which is why that column says “not recorded” rather than 0. “Of those validation only” counts instances whose input parameter onlyValidation is true at instance start. Deliberately only the input parameter: some processes set the same variable internally later on, where it means something else, and counting both together produces wrong numbers. Both spellings (boolean and string) are merged; a value that cannot be interpreted appears as “undecidable” rather than as false, and instances without the input parameter appear as “marked only inside the process” rather than as a dry run.
